# Page 70h and Vendor CDB Coexistence

Next-release APSU/iLT firmware will support CMIS Page 70h while vendor CDB remains available during a transition period. We decided that both control surfaces must operate on one shared effective APSU/iLT state keyed by Ethernet interface, side, lane set, and control field. Because Page 70h and vendor CDB both reach the module through the CMIS I2C-MCI interface, coexistence validation is based on ordered mixed-session writes, not true concurrent control access. An accepted write through either surface updates the keyed state, both surfaces read back the same effective keyed state, the later ordered transaction wins only for the same key, CMIS reserved fields follow CMIS reserved field behavior, and non-reserved invalid or unsupported writes must not create partial disagreement. CMIS Page 70h remains the formal pass/fail interface for release validation, while vendor CDB is retained for compatibility and diagnostic correlation.
