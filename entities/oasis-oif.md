# Optical Internetworking Forum (OIF)

The Optical Internetworking Forum (OIF) is the standards organization that publishes the Common Management Interface Specification and related CMIS implementation agreements.

The earlier starter version of this page incorrectly conflated OIF CMIS with OASIS content-management CMIS. In this wiki, **CMIS** means the OIF Common Management Interface Specification for managed modules.

## Role

- Publishes [oif-cmis-05-4](../sources/oif-cmis-05-4.md) and prior base CMIS Implementation Agreements.
- Maintains the CMIS base specification and related OIF supplements.
- Coordinates with industry standards and form-factor organizations relevant to optical internetworking.
