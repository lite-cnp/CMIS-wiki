# MIPI I3C Basic v1.1.1 FAQ

This public FAQ is a useful companion to the MIPI I3C Basic specification family. It is not the spec itself, but it confirms the current public Basic version lineage, licensing model, and major feature expectations.

## Why It Matters

- Confirms that MIPI I3C Basic is publicly available for non-members.
- Summarizes version compatibility, errata history, and the direction of I3C v1.2 / I3C Basic v1.2.
- Confirms that MIPI recommends implementers move to I3C v1.2 / I3C Basic v1.2 as the newest recommended versions.
- Clarifies that the full I3C specification is member-only, while the Basic subset is the public implementation path.
- Provides a public reference for implementation questions while the full specification remains gated.

## Key Statements For CMIS Over I3C

- `I3C Basic v1.2` is primarily an editorial update to `I3C Basic v1.1.1`.
- `I3C Basic` is the public subset available to non-members.
- `I3C v1.2` is the newest recommended full spec version, but it is not publicly downloadable.
- Public companion docs and errata-aware guidance are meant to support implementers.
