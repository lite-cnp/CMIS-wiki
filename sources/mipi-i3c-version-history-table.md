# MIPI I3C and I3C Basic Version History Table

This public feature table summarizes how I3C and I3C Basic features evolved across versions. It is a compact reference for deciding which capabilities are normative, optional, or version-dependent.

## Why It Matters

- Helps anchor the difference between I3C v1.1.1 / v1.2 and I3C Basic v1.1.1 / v1.2.
- Useful for implementation scoping when matching a target stack to the intended feature subset.
- Supports version-aware decisions in the CMIS-over-I3C roadmap.
