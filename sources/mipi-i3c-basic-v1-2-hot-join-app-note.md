# MIPI I3C Basic v1.2 Hot-Join Application Note

This public MIPI application note explains Hot-Join for MIPI I3C v1.2 and I3C Basic v1.2. It is informative rather than normative, but it is relevant to CMIS-over-I3C bring-up because the draft I3CMCI transport explicitly uses IBI, target readiness, and dynamic bus participation behaviors.

## Why It Matters

- Clarifies Hot-Join usage and restrictions for controller and target devices.
- Provides context for systems where a target may join a bus after initial setup.
- Helps frame when IBI and dynamic address flow should be considered in implementation planning.
