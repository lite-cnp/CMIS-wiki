# MIPI I3C Virtual Devices and Virtual Targets Application Note

This public application note covers advanced I3C usage patterns around virtual devices and virtual targets. For the CMIS-over-I3C work, it is relevant as a design reference for multi-target or abstraction-heavy system architecture.

## Why It Matters

- Provides implementation context for systems that may expose virtualized or proxy-managed I3C behavior.
- Helps distinguish direct physical target handling from more abstract device models.
- Useful when evaluating whether a production adapter or lab bridge should present virtualized endpoints.
