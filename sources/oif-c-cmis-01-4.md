# OIF-C-CMIS-01.4

OIF-C-CMIS-01.4 is the Coherent CMIS implementation agreement. It specifies CMIS extensions for coherent modules, with the initial release family focused on 400ZR.

## Scope

C-CMIS extends the base [management-memory-map](../concepts/management-memory-map.md), [versatile-diagnostics-monitoring](../concepts/versatile-diagnostics-monitoring.md), and [command-data-block](../concepts/command-data-block.md) model for coherent transmission capabilities. It includes coherent-specific pages, terminology mapping to CMIS and 400ZR concepts, coherent capabilities advertisement, and C-CMIS CDB commands.

## Main Areas

- Memory page structure for coherent modules.
- Terminology mapping across C-CMIS, CMIS, and 400ZR.
- Coherent extensions to VDM, media interface registers, and host interface registers.
- Coherent module capability advertisement.
- C-CMIS-specific CDB command IDs.
