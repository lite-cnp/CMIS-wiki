# What's New in MIPI I3C Basic and the I3C Ecosystem

This webinar summarizes the public I3C Basic ecosystem and the evolution of the I3C family. It is not a specification, but it is useful background when positioning CMIS-over-I3C implementation choices against the broader MIPI ecosystem.

## Why It Matters

- Shows how MIPI framed I3C as a broad control bus, not just a sensor interface.
- Provides ecosystem context for HCI, interoperability, and power-efficiency discussions.
- Useful as a background reference, not a normative source.
